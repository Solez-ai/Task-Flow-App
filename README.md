# 💼 FocusFlow – Minimalist Productivity Web App
#Web URL - https://thetaskflow.netlify.app/

**FocusFlow** is a clean, distraction-free productivity web app built to help you stay focused, track your tasks, and build consistent work habits using the Pomodoro Technique and minimalist design principles.

> 🎯 “Flow Through Your Focus. One Task at a Time.”

---

## 🧠 Why FocusFlow?

Most productivity tools are bloated with features you’ll never use. FocusFlow takes a **minimal yet powerful** approach—giving you exactly what you need to stay focused and productive, without distractions. Perfect for students, creators, professionals, or anyone trying to build better habits.

---

## 📦 Key Features

### ⏲️ 1. Pomodoro Focus Modes
- **Classic Mode**: Manual 25-minute focus sessions + 5-minute breaks.
- **Study Mode**: Automatically cycles focus/break timers.
- Option to **skip breaks** or **auto-start next session**.

### ✅ 2. Task Manager
- Add, edit, and complete daily tasks.

### 📅 3. Monthly Calendar View
- Highlights days with completed tasks or Pomodoro sessions.
- Clean and consistent design that matches dark/light mode.

### 📊 4. Daily Productivity Stats
- Tracks:
  - ✔️ Pomodoros completed
  - ✔️ Tasks finished
  - ✔️ Focused time (in minutes)
- Resets daily for fresh starts.

### 💡 7. Motivational Quotes
- Displays fresh, inspiring quotes per session.
- Curated custom quotes included.

### 🔘 8. Micro Tool Buttons
#### 📅 Mini Calendar
- Pop-up version of your work calendar with color coding.
- Elegant and consistent with main theme.

#### 🧮 Quick Calculator
- Built-in simple calculator for fast math.
- Saves time and avoids breaking focus.
